# Promo page (docs/index.html)

Scope: the single static promo page on GitHub Pages. Visitor mode: Persuade.

Audience and job: an instructor or classmates open it for a minute or two, on a projector or a laptop in daylight. They should grasp what fraudsense does, who it is for, and that its numbers are honest. The one action is the link to the GitHub repository.

Constraints (user-pinned):
- Every sentence and number exactly as in docs/content.md, same five sections in the same order.
- The name on the sheet is "fraudsense"; never a person's name, email or username.
- Plain HTML and CSS only: no JavaScript, no external fonts, no image or font files.

## Direction contract

THESIS: The page is one exam answer sheet that the tool hands in and the data marks. It refuses the dark developer-tool page with a terminal window and a feature grid.

OWN-WORLD: White feint-ruled paper with a pale printed margin line; blue-black typewriter text sitting on the rules; headings underlined the way a typist underlines; one marking red used only for the marker's marks: a hand-drawn ring, underlines, ticks, crosses, a boxed comment. Code is the same typed hand on a faint blue wash.

STORY: The visitor reads what the tool is for, sees it scored 68 out of 157 before being told anything else about quality, believes the page because it marks itself down, and follows the link to the repository.
